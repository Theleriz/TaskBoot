# Task Tracker

Персональный трекер задач: матрица Эйзенхауэра, Kanban-доска, Pomodoro-таймер и рабочее пространство с заметками и секретами. Задачи едины для всех вкладок. У каждой задачи есть детали: описание, чек-лист и ссылки.

Реализовано по двум ТЗ: [базовому](../task_manager_description.md) и [расширению 02](feature_document_02.md). Есть две равноценные версии.

## Веб-версия — `index.html`

Один файл без зависимостей. Откройте его двойным щелчком в любом браузере.

Чтобы открыть его в отдельном окне Edge, как программу, дважды щёлкните `open-web.cmd` или выполните в PowerShell:

```bash
Start-Process msedge "--app=file:///C:/projects/TaskManager/win32/index.html"
```

Данные хранятся в `localStorage` браузера: `taskTracker.tasks`, `taskTracker.settings`, `taskTracker.notes`, `taskTracker.secrets`. В другом браузере список будет свой.

## Нативная версия для Windows — `bin\TaskTracker.exe`

WPF на .NET Framework 4.8, встроенном в Windows. Сборка встроенным компилятором, ничего устанавливать не нужно:

```bash
build.cmd
```

Значок приложения (`app.ico`) встраивается в `.exe` при сборке, поэтому виден в Проводнике и на закреплённой кнопке панели задач. Сгенерировать его заново: `powershell -ExecutionPolicy Bypass -STA -File tools\make-icon.ps1`.

Данные хранятся в `%APPDATA%\TaskTracker\data.json`, поля те же, что в веб-версии. Каталог можно переопределить переменной `TASKTRACKER_DATA_DIR`.

Если включён Smart App Control, Windows не даст запустить неподписанный `.exe`. В этом случае используйте веб-версию.

## Настройки и темы (нативная версия)

Шестерёнка в правом верхнем углу открывает настройки. Режимы темы:

- **Системная** — светлая или тёмная, как в Windows, с переключением на лету.
- **Светлая** и **Тёмная**.
- **Своя** — фон и акцент: hex-код, готовые образцы или стандартный выбор цвета Windows. Ниже подбираются фоны, подходящие к акценту (кнопка «Ещё варианты» даёт новые), и сочетающиеся акценты.
- **Случайная** — кнопка «Сгенерировать» создаёт новую пару цветов.

Любую текущую тему можно сохранить под своим именем и потом применить из списка. Все цвета интерфейса вычисляются из пары «фон + акцент» (`src/Theme.cs`). Настройки хранятся в `data.json`, в разделе `settings.theme` и `settings.themes`.

## Уведомления об окончании таймера

Если окно открыто и активно, внутри него появляется короткое сообщение. Если окно свёрнуто или в фоне:

- **Нативная версия** показывает уведомление Windows («Работа окончена. Начинается отдых: 15 мин.») и мигает кнопкой на панели задач. Щелчок по уведомлению или по значку в трее открывает окно.
- **Веб-версия** показывает уведомление браузера, если оно разрешено. Разрешение браузер спросит при первом нажатии «Старт». Заголовок вкладки при этом мигает, пока вы к ней не вернётесь. Если уведомления запрещены или не поддерживаются, остаются звук и мигание заголовка, а под таймерами появляется подсказка.

## Секреты не шифруются

Правила защиты данных для репозитория: [docs/secrets-policy.md](../docs/secrets-policy.md). Переменные окружения задаются в `.env.local` (не попадает в git); `.env` в корне — пример.

В обеих версиях значения секретов хранятся в открытом виде (в `localStorage` или в `data.json`). Об этом предупреждает надпись в интерфейсе. Это не менеджер паролей.

## Управление

- Щелчок или Enter на карточке открывают детали. Esc, крестик или щелчок по фону их закрывают.
- Карточки можно перетаскивать между зонами. Перетаскивание не открывает детали.
- В нативной версии: Ctrl+1…4 переключают вкладки, Ctrl+N переводит курсор в поле новой задачи, Delete на выделенной карточке удаляет её.

## Структура нативной версии

- `src/Store.cs` — модель (задачи с деталями, заметки, секреты, настройки), загрузка с миграцией, сохранение.
- `src/Boards.cs` — матрица и канбан: карточки с индикаторами, drag-and-drop.
- `src/Details.cs` — панель деталей задачи.
- `src/Workspace.cs` — вкладка «Пространство».
- `src/Pomodoro.cs` — таймеры, автопереключение, звуки.
- `src/MainWindow.cs` — шапка, вкладки, виджет таймера.
- `src/Theme.cs` — палитра (светлая и тёмная по настройке Windows) и стили.
