# Техническое задание: Task Tracker

## 1. Общие сведения

**Наименование:** Task Tracker — персональный трекер задач с матрицей Эйзенхауэра, Kanban-доской и Pomodoro-таймером.

**Тип приложения:** одностраничное веб-приложение (SPA), клиентское, без бэкенда.

**Форм-фактор:** десктоп-браузер (основной), адаптив под мобильные экраны.

**Платформы:** веб-приложение (папка `web/`, кросс-платформенное: браузер, GitHub Pages) — основная и единственная кодовая база интерфейса; приложение для Windows (папка `win32/`) — оболочка WebView2, которая показывает то же веб-приложение и добавляет возможности Windows (хранение в файле, уведомления, панель задач). Требования ТЗ относятся к веб-приложению и тем самым к обеим платформам. Устройство — `docs/architecture.md`.

**Цель:** дать пользователю единое рабочее пространство, в котором одни и те же задачи можно раскладывать по приоритетам (матрица), вести по стадиям (канбан) и работать над ними в режиме Pomodoro — без дублирования данных между инструментами.

**Ключевой постулат (аксиома приложения):** все задачи едины. Одна задача существует в единственном экземпляре и одновременно отображается во всех представлениях. Изменение задачи в одном представлении немедленно отражается во всех остальных.

## 2. Термины

| Термин | Значение |
|---|---|
| Задача | Единица работы: заголовок + приоритетная зона + стадия |
| Квадрант | Позиция задачи в матрице Эйзенхауэра (`q1`–`q4`) |
| Стадия | Позиция задачи в Kanban (`todo` / `doing` / `done`) |
| Помидор | Один цикл работы таймера Pomodoro |
| Глобальный виджет | Индикатор активного таймера в шапке приложения |
| Зона drop | Область, принимающая перетаскиваемую задачу (`data-zone`) |

## 3. Функциональные требования

### 3.1. Управление задачами

| ID | Требование | Приоритет |
|---|---|---|
| F-01 | Пользователь может создать задачу, указав только её заголовок | Обязательно |
| F-02 | Новая задача по умолчанию попадает в квадрант `q2` («Важно · Не срочно») и в стадию `todo` | Обязательно |
| F-03 | Пользователь может удалить задачу; удаление убирает её из всех представлений | Обязательно |
| F-04 | Задача отображается одновременно в матрице (по квадранту) и в канбане (по стадии) | Обязательно |
| F-05 | Перемещение задачи в матрице не меняет её стадию в канбане | Обязательно |
| F-06 | Перемещение задачи в канбане не меняет её квадрант в матрице | Обязательно |
| F-07 | Список задач сохраняется между перезагрузками страницы | Обязательно |
| F-08 | Заголовок задачи не может быть пустым или состоять только из пробелов | Обязательно |
| F-09 | Редактирование заголовка существующей задачи | Опционально |

### 3.2. Матрица Эйзенхауэра

| ID | Требование | Приоритет |
|---|---|---|
| F-10 | Отображаются 4 квадранта в сетке 2×2 | Обязательно |
| F-11 | Квадранты подписаны: «Важно · Срочно», «Важно · Не срочно», «Не важно · Срочно», «Не важно · Не срочно» | Обязательно |
| F-12 | Перетаскивание задачи между квадрантами меняет её приоритетную зону | Обязательно |
| F-13 | В заголовке каждого квадранта отображается счётчик задач в нём | Обязательно |
| F-14 | Пустой квадрант отображает плейсхолдер «пусто» | Желательно |

### 3.3. Kanban-доска

| ID | Требование | Приоритет |
|---|---|---|
| F-20 | Отображаются 3 колонки: «TODO», «В работе», «Готово» | Обязательно |
| F-21 | Перетаскивание задачи между колонками меняет её стадию | Обязательно |
| F-22 | В заголовке каждой колонки отображается счётчик задач в ней | Обязательно |
| F-23 | Пустая колонка отображает плейсхолдер «пусто» | Желательно |

### 3.4. Pomodoro-таймер

| ID | Требование | Приоритет |
|---|---|---|
| F-30 | Отображаются два независимых таймера: «Работа» и «Отдых» | Обязательно |
| F-31 | Длительность по умолчанию: работа — 45 минут, отдых — 15 минут | Обязательно |
| F-32 | Каждый таймер имеет кнопки «Старт», «Пауза», «Сброс» | Обязательно |
| F-33 | Пользователь может изменить длительность каждого таймера в минутах | Обязательно |
| F-34 | Допустимый диапазон работы — 1–180 мин, отдыха — 1–60 мин | Обязательно |
| F-35 | Изменённые длительности сохраняются между перезагрузками | Обязательно |
| F-36 | По завершении работы автоматически запускается отдых (через 400 мс) | Обязательно |
| F-37 | По завершении отдыха автоматически запускается работа (через 400 мс) | Обязательно |
| F-38 | По завершении таймера воспроизводится звуковой сигнал (разный для работы и отдыха) | Желательно |
| F-39 | Активный таймер визуально выделяется (подсветка карточки) | Желательно |

### 3.5. Глобальный виджет таймера

| ID | Требование | Приоритет |
|---|---|---|
| F-40 | Виджет располагается в правом верхнем углу, в шапке приложения | Обязательно |
| F-41 | Виджет отображается на всех вкладках, кроме вкладки Pomodoro | Обязательно |
| F-42 | Если идёт отсчёт работы — виджет красный и показывает остаток работы | Обязательно |
| F-43 | Если идёт отсчёт отдыха — виджет зелёный и показывает остаток отдыха | Обязательно |
| F-44 | Если таймер на паузе — виджет серый и показывает остаток | Желательно |
| F-45 | Если таймеры не запускались или сброшены — виджет серый, значение «—» | Желательно |
| F-46 | Пока идёт отсчёт — индикатор пульсирует | Опционально |

### 3.6. Навигация

| ID | Требование | Приоритет |
|---|---|---|
| F-50 | Вкладки (Эйзенхауэр / Канбан / Pomodoro) расположены слева в шапке | Обязательно |
| F-51 | Активная вкладка визуально выделена | Обязательно |
| F-52 | Переключение вкладок не теряет состояние задач и таймеров | Обязательно |
