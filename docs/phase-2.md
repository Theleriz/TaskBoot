# Фаза 2 — организация

Утверждено 2026-10-28. Часть [дорожной карты](roadmap.md) (функции 10–12), опирается на [фазу 0](phase-0.md) и [фазу 1](phase-1.md); устройство приложения — [architecture.md](architecture.md).

## Цель

Три функции, которые меняют то, как организована работа в приложении:

- **рабочие пространства** — свои наборы вкладок под цель («Учёба», «Работа»): добавить, убрать, переставить вкладки;
- **бэклог и долгосрочные задачи** — задачи «на потом», «Взять на сегодня» в TODO, цели с прогрессом;
- **статистика активности** — что и когда сделано: задачи, Pomodoro, карточки, заметки.

Решения владельца проекта от 2026-10-28, принятые до этого плана: фаза идёт второй, перед «Голосом»; функция называется «Рабочее пространство»; задачи, заметки и карточки общие для всех рабочих пространств.

## Принятые решения

| # | Вопрос | Решение | Причина |
|---|---|---|---|
| 1 | Порядок выпусков | v2.3.0 — рабочие пространства и начало сбора статистики; v2.4.0 — бэклог и цели; v2.5.0 — экран статистики | Статистика показывает данные только с момента начала сбора, поэтому он включается в первом же выпуске |
| 2 | Что собирать для статистики | Счётчики по дням: задач создано и выполнено, рабочих сессий Pomodoro и минут, правок заметок. У задачи — дата выполнения. Повторения карточек — из их истории (фаза 1) | Около 365 маленьких записей в год вместо журнала событий; достаточно для тепловой карты, недельных графиков и серий |
| 3 | Переключение рабочих пространств | Список слева в шапке, перед вкладками | Видно текущее пространство; переключение в один щелчок |
| 4 | Настройка вкладок | Окно «Настроить пространство» из того же списка: название, вкладки с галочками, порядок перетаскиванием и стрелками, удаление пространства | Перестановка работает и без мыши |
| 5 | Что всегда видно | Шестерёнка настроек и виджет Pomodoro в шапке — в любом пространстве; в пространстве хотя бы одна вкладка | Из любого набора вкладок можно попасть в настройки, таймер не теряется |
| 6 | Бэклог | Признак задачи «в бэклоге»: на досках такие задачи не показываются; «Взять на сегодня» ставит задачу в TODO, по умолчанию в «Важно · Не срочно» | Задача остаётся одной, без копий и рассинхронизации |
| 7 | Долгосрочные цели | Список целей: название, описание, необязательный срок. Задачи привязываются к цели в панели деталей; прогресс — доля выполненных привязанных задач | Простая модель; подцели — позже, если понадобятся |
| 8 | Графики | Свои SVG (тепловая карта, столбики), без библиотеки | Нужны два простых вида графиков (D-05) |

Действуют правила фазы 1: точные версии зависимостей не моложе двух недель, кроме исправлений уязвимостей; изменение формата данных — только через новую версию схемы с миграцией и тестом.

## Критерии готовности фазы

- Пользователь создаёт рабочие пространства, выбирает и переставляет в них вкладки; после обновления у прежних пользователей всё как было.
- Задачи из бэклога не мешают на досках и одним действием попадают в TODO; цели показывают прогресс по задачам.
- Статистика показывает активность по дням с момента выхода v2.3.0 и историю карточек; всё считается локально.
- Данные v3 читаются (тесты миграций 3 → 4 → 5); CI зелёный; выпущены v2.3.0, v2.4.0, v2.5.0.

## Вне объёма фазы

- Метки задач и фильтр задач по рабочему пространству — когда понадобятся.
- Подцели и вложенные цели.
- Синхронизация между устройствами (открытый вопрос дорожной карты).
- Статистика по времени суток (для неё понадобился бы журнал событий вместо счётчиков по дням).
