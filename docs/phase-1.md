# Фаза 1 — знания

Утверждено 2026-10-20. Часть [дорожной карты](roadmap.md), опирается на [фазу 0](phase-0.md); устройство приложения — [architecture.md](architecture.md).

## Цель

Две функции из дорожной карты: **пространства знаний** (заметки в папках, Markdown, формулы, поиск, RegEx, связи с задачами) и **карточки как в Anki** (колоды, интервальные повторения). Обе работают офлайн и одинаково в вебе и в приложении для Windows.

## Принятые решения

| # | Вопрос | Решение | Причина |
|---|---|---|---|
| 1 | Хранение | Схема данных v2 с миграцией из v1. В браузере — IndexedDB вместо localStorage (данные переносятся автоматически, старый ключ остаётся нетронутым). В оболочке — прежний `data.json` | В localStorage помещается около 5 МБ — для базы заметок мало |
| 2 | Где живут заметки | Вкладка «Пространство» становится деревом папок с заметками. Нынешние заметки переносятся в корень, секреты — отдельный раздел там же | Не появляется второго места для заметок |
| 3 | Редактор | CodeMirror 6 (MIT) с подсветкой Markdown; режимы «редактор», «просмотр», «рядом» | Зрелый редактор, справляется с большими текстами |
| 4 | Markdown и формулы | markdown-it (MIT) с отключённым HTML; KaTeX (MIT) для `$…$` и `$$…$$`, шрифты KaTeX входят в сборку | Без HTML в заметке нельзя внедрить скрипт; формулы работают без интернета |
| 5 | Поиск | Полнотекстовый — MiniSearch (MIT): по префиксу, с опечатками, «ё» = «е». RegEx — в Web Worker с тайм-аутом 1 с | Неудачное регулярное выражение не подвешивает интерфейс |
| 6 | Карточки | Отдельная вкладка «Карточки»; колоды; типы «вопрос–ответ» и cloze (`{{c1::…}}`); планировщик FSRS — ts-fsrs (MIT) | Современный алгоритм интервальных повторений, как в Anki |
| 7 | Размер сборки | Редактор и KaTeX — отдельные части сборки, загружаются при первом открытии заметок | Доски открываются так же быстро, как сейчас |
| 8 | Версии зависимостей | Точные версии, вышедшие не меньше двух недель назад (дополняет D-02) | Защита от свежих скомпрометированных выпусков |

Лицензии указаны на 2026-10-20 и сверяются при подключении (D-01); каждая зависимость попадает в `THIRD_PARTY_NOTICES.md` (D-03).

## Ветки и выпуски

По правилам [CONTRIBUTING.md](../CONTRIBUTING.md) и [versioning.md](versioning.md):

- **Шаг 1.0** — ветка `docs/phase-1`, обычный pull request.
- **Шаги 1.1–1.4** — ветка `feature/knowledge`. Бета `v2.1.0-beta.N` из ветки, проверка (CI, браузер, приложение для Windows, старые данные), затем pull request и выпуск `v2.1.0` из `main`.
- **Шаг 1.5** — ветка `feature/flashcards` от `main` после v2.1.0. Бета `v2.2.0-beta.N`, затем pull request и выпуск `v2.2.0`.

## Критерии готовности фазы

- Заметки в папках с Markdown и формулами работают офлайн в вебе и в оболочке; прежние заметки перенесены без потерь.
- Полнотекстовый поиск и поиск по RegEx находят заметки; зависшее регулярное выражение не блокирует интерфейс.
- Заметки и задачи связываются в обе стороны.
- Карточки повторяются по FSRS; карточку можно создать из заметки.
- Данные браузера перенесены из localStorage в IndexedDB; данные v1 читаются (тест миграции).
- CI зелёный, выпущены v2.1.0 и v2.2.0.

## Вне объёма фазы

- Импорт колод Anki (`.apkg` — zip с базой SQLite, потребует sql.js) — отдельным шагом позже.
- Хранение заметок отдельными файлами `.md` в папке пользователя (как в Obsidian).
- Wiki-ссылки между заметками (`[[Название]]`) — после MVP, если понадобятся.
