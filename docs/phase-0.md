# Фаза 0 — фундамент гибрида

Утверждено 2026-10-20. Часть [дорожной карты](roadmap.md), архитектура — вариант A: веб — основная кодовая база, нативное приложение для Windows — оболочка на WebView2.

## Цель

Веб-версия становится основной кодовой базой и догоняет нативную по функциям. Нативное приложение превращается в оболочку WebView2, показывающую тот же интерфейс офлайн. Данные пользователей переносятся без потерь.

## Принятые решения

| # | Вопрос | Решение | Причина |
|---|---|---|---|
| 1 | Стек веб-версии | TypeScript + React + Vite | Типы для растущей кодовой базы; React нужен для Excalidraw (whiteboard) |
| 2 | Платформа оболочки | .NET Framework 4.8, SDK-проект (сборка через `dotnet`) | Получателю не нужно ничего устанавливать; при этом доступны NuGet и современный C# |
| 3 | Хранение данных в оболочке | `%APPDATA%\TaskTracker\data.json` через мост к C# | Один файл, переживает очистку кэша WebView2, совместим с текущими данными |
| 4 | Публикация веба | GitHub Pages | Кросс-платформенная ссылка. Для приватного репозитория Pages требуют платный план GitHub |

## Критерии готовности фазы

- Веб-сборка умеет всё, что умеет нынешняя нативная версия, включая настройки и темы.
- Оболочка показывает тот же интерфейс без интернета; данные в `%APPDATA%`; старые данные переносятся автоматически.
- CI зелёный; есть zip в Releases и ссылка на Pages.
- Старый WPF-интерфейс удалён из кода, в истории остаётся тег `wpf-legacy`.

## Что требуется от владельца проекта

- Установить .NET SDK для сборки оболочки (нужен к шагу 0.5): `winget install Microsoft.DotNet.SDK.10` (точный id пакета проверить через `winget search Microsoft.DotNet.SDK`).
- Решить видимость репозитория для GitHub Pages (публичный или платный план) — к шагу 0.6.
